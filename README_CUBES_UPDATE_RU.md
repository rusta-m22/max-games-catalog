# Обновление «Кубомания: мечта маджонг»

## Как посмотреть игру

Откройте отдельный файл `Kubomaniya_Mechta_Madzhong.html` в современном браузере. Внутри уже находятся игра и все необходимые библиотеки; интернет не требуется. Это предпросмотр, его открытие не обновляет сайт Amvera.

## Как обновить существующий каталог

1. Скачайте и распакуйте `Kubomaniya_Mechta_Madzhong_Update.zip` на компьютере.
2. Откройте папку проекта `max-games-catalog`, в которой находятся `amvera.yml`, `package.json` и папка `site`.
3. Скопируйте содержимое архива в эту папку с сохранением путей. Разрешите заменить совпадающие файлы. Папка `site` из архива должна объединиться с существующей `site`, а не оказаться внутри `site/site`.
4. Сохраните изменения в GitHub / отправьте код в Amvera обычным способом для вашего проекта. Дождитесь завершения развёртывания.
5. Откройте каталог, обновите страницу и запустите «Кубомания: мечта маджонг». Прямая ссылка на игру остаётся `play.html?game=cubes`.

Если работаете через сайт GitHub, открыть нужно репозиторий `rusta-m22/max-games-catalog`. Новые файлы должны оказаться по тем же путям, которые указаны ниже. Сам ZIP не заменяет файлы сайта: сначала его нужно распаковать.

## Какие файлы игры меняются

- `site/js/data.js` — новое название, описание и обложка в каталоге.
- `site/js/play.js` — запуск обновлённой игры.
- `site/js/cubes.js` — экран игры и управление.
- `site/js/cubes-engine.js` — парная механика, 10 раскладок и сохранения.
- `site/js/cubes-view.js` — объёмная сцена, анимации, масштаб, Canvas.
- `site/js/cubes-art.js` — оригинальные символы плиток.
- `site/cubes.css` — фон и интерфейс телефона / компьютера.
- `site/assets/cubes-card.svg` — карточка игры.

В архив также входят инструкция, скрипт отдельной сборки и проверки. Они не нужны для ручного копирования только рабочих файлов сайта.

## Что будет в игре

10 разных фигур, 3 фона и 3 оформления кубиков. Каждая новая партия меняет фигуру, фон и оформление. По умолчанию игра без таймера; режим на время находится в меню. Игра занимает доступный экран телефона. Совпадения дают эффекты и серию очков.

Старый сектор и очки сохраняются при переходе. Старая незаконченная партия с тройками заменяется новой парной раскладкой; исходное старое сохранение остаётся на устройстве.

## Публикация и проверки

Архив предназначен для существующего каталога из 19 игр. Сервер, конфигурация Amvera и настройки рекламы не меняются. Процесс развёртывания может перезапустить приложение согласно текущим настройкам Amvera.

Пройдены 9 проверок правил (в том числе 200 полностью решённых начальных раскладок), 30 браузерных проверок, проверка 10 форм, мыши и структуры каталога. Размеры экранов: 320×568, 360×640, 390×844, 430×932, 768×1024, 844×390, 667×375, 1366×768, 1920×1080. Проверка на физическом телефоне и в приложении MAX ещё не выполнена.

Изменения в этом архиве подготовлены и проверены локально. На Amvera они автоматически не опубликованы.
