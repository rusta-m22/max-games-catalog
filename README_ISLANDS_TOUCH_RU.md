# Острова кубиков 3D — удобное перетаскивание, версия 1.2

Фигура при переносе находится выше пальца. Высокие фигуры приподнимаются сильнее, чтобы нижние кубики тоже не закрывались пальцем. При отпускании фигура устанавливается в подсвеченные клетки.

Сохранено предыдущее исправление: переносимые кубики цветные, непрозрачные, с тёмной окантовкой. Нельзя установить фигуру в занятое место. Отмена перетаскивания не тратит ход. Управление мышью осталось прежним.

## Как установить

1. Распакуйте `Ostrova_Kubikov_3D_Touch_Fix.zip` на компьютере.
2. В папке существующего проекта `max-games-catalog` откройте `site/js`.
3. Замените два файла из архива: `islands.js` и `islands-view.js`. Сохраняйте пути: `site/js/islands.js` и `site/js/islands-view.js`.
4. Сохраните изменения в репозитории и отправьте обновление в Amvera обычным способом для вашего проекта.
5. После успешного развёртывания обновите страницу игры и проверьте перенос на телефоне.

Остальные игры, включая новую Кубоманию, сохраняются. Прогресс Островов не сбрасывается. Архив сам по себе не обновляет сайт.

Для предварительного просмотра откройте `Ostrova_Kubikov_3D_v1_2.html` в браузере. Весь код находится внутри этого файла. На иллюстрации предпросмотра полупрозрачный кружок обозначает место касания; это отметка для демонстрации зазора, а не новый элемент игры.

Полный каталог `IGRY_MAX_19_Full.zip` и общее обновление `IGRY_MAX_19_Update.zip` также включают это исправление.
