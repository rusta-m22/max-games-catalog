# Обновление каталога: 19 игр

## Что готово

1. Новая игра **«Острова кубиков 3D»**: две отдельные партии (рекорд и путешествие), 18 уровней, серии, поворот и волна за игровую энергию, подсказка, объёмная сцена и эффекты.
2. **«Сокровища орбиты v4»**: весь доступный экран, крупное поле, счётчики и управление внутри игры, сохранение прежнего прогресса.
3. Новая карточка, поиск и запуск в каталоге. Всего 19 игр. Мемасики не включены.
4. **«Кубомания: мечта маджонг»**: парный маджонг, 10 объёмных фигур, 3 оформления плиток и фона, эффекты совпадения и интерфейс на весь доступный экран. Отдельная инструкция: `README_CUBES_UPDATE_RU.md`.

## Как посмотреть прямо сейчас

`Ostrova_Kubikov_3D_v1_2.html` и `Sokrovishcha_Orbity_3D_v4.html` — самостоятельные файлы. Скачайте и откройте браузером на компьютере. Сервер и установка не нужны; все игровые ресурсы внутри. Локальный просмотр HTML на телефоне зависит от приложения, открывающего скачанный файл; обычная размещённая HTTPS-версия рассчитана на мобильный браузер и MAX.

## Что находится в архивах

- **IGRY_MAX_19_Update.zip** — только новые и изменённые файлы. Распаковать **в корень существующего проекта**, заменив совпадающие файлы и сохранив структуру папок. Не загружать ZIP как один файл в репозиторий.
- **IGRY_MAX_19_Full.zip** — полный исходный каталог со всеми 19 играми. Удобен для новой локальной копии. Папка `IGRY_MAX` внутри архива содержит корень проекта.

Пакет подготовлен относительно дерева GitHub `b0981a040059b91cbccc80aba3c1feaf5d0dc0b8`, прочитанного во время работы. Если после этого вы меняли те же файлы, изменения нужно объединить, сохранив вашу новую работу.

## Контроль перед публикацией

**Затронуты:** новая игра islands, игры orbit и cubes, карточки/маршрут каталога; добавлены проверки и документация. Код остальных 16 игр сохранён.

**Запуск и реклама:** `amvera.yml`, `amvera-start.mjs`, `serve.mjs`, рекламный модуль и его конфигурация не изменены. Зависимости не добавлены.

**Перезапуск:** при выкладке новой версии через существующий процесс Amvera ожидается запуск обновлённого приложения. Прямую команду перезапуска мы не выполняли. В существующем `amvera.yml` включён zeroDowntime; фактическую выкладку следует проверить в Amvera.

**Проверки:** аудит 512 файлов и 154 локальных ссылок; 19 уникальных игр; 68 автоматических тестов правил/интеграции; 60 браузерных проверок двух игр. Отдельно оба автономных HTML прошли запуск без сетевых ресурсов и проверку на четырёх размерах окна. В отчётах `docs/release-19-qa` есть результаты браузера.

**Ограничение проверки:** использован Chromium и эмуляция касаний. Настоящие Android/iPhone и приложение MAX необходимо проверить после тестовой выкладки; производительность на реальных телефонах не измерялась.

## Статус публикации

Подключение GitHub позволяет читать `rusta-m22/max-games-catalog`, но попытка создать рабочую ветку отклонена: `403 Resource not accessible by integration`. Ветка и коммит не созданы, изменения на Amvera не отправлены. Архив — готовое обновление, а не подтверждение публикации.

После успешной загрузки в действующий проект маршруты будут:

- новая игра: `/play.html?game=islands`;
- орбита: `/play.html?game=orbit`.
- Кубомания: `/play.html?game=cubes`.

Для локальной проверки полного проекта с установленным Node.js: `npm ci`, затем `npm run preview`; открыть `http://127.0.0.1:8080/`. Проверки: `npm test` и `npm run audit`. Автономные сборки: `node scripts/build-islands-preview.mjs` и `node scripts/build-orbit-preview.mjs`.

## Исправление Островов кубиков 1.1

Переносимые фигуры теперь цветные и непрозрачные, с тёмным контуром. Неподходящее место обозначается красным и крестиками; подсветка линии не закрывает фигуру. Для каталога с уже установленной игрой достаточно заменить `site/js/islands-view.js` из отдельного архива `Ostrova_Kubikov_3D_Contrast_Fix.zip`. Остальные игры и сохранения не затрагиваются.

## Обновление Кубомании

`Kubomaniya_Mechta_Madzhong.html` — самостоятельная игра для просмотра; `Kubomaniya_Mechta_Madzhong_Update.zip` — только обновление Кубомании для существующего каталога. Оба общих архива также включают новую Кубоманию и исправление видимости фигур в Островах.

Текущие проверки Кубомании: 9 тестов правил, включая 200 полностью решённых стартовых раскладок; 30 браузерных проверок, 10 визуально проверенных форм и выбор мышью. Аудит текущего каталога: 518 файлов, 164 локальные ссылки, 19 игр. Результаты — `docs/cubes-qa/`. Цифры 68 / 60 выше относятся к предыдущему выпуску; новый общий прогон всех игр не завершился. Новая Кубомания и сборка проверены отдельно.

## Исправление Островов кубиков 1.2

Фигура при переносе автоматически поднимается над пальцем с учётом своей высоты и размера клеток. При отпускании она ставится в подсвеченное место. Отдельный архив — `Ostrova_Kubikov_3D_Touch_Fix.zip`, инструкция — `README_ISLANDS_TOUCH_RU.md`. Исправление цвета из версии 1.1 включено.
