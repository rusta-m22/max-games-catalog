# Сокровища орбиты: готовое обновление

## Сначала проверьте игру

Откройте отдельный файл `Sokrovishcha_Orbity_v2.html` в Chrome или другом современном браузере. Он содержит игру целиком и работает без загрузки дополнительных файлов. Пройдите первые миссии, откройте карту и попробуйте бур и заряжаемый импульс.

## Как установить в наш каталог

1. Распакуйте `Sokrovishcha_Orbity_v2_Update.zip` в отдельную папку.
2. Откройте GitHub Desktop и выберите `max-games-catalog`.
3. Нажмите **Repository → Show in Explorer**. Откроется корневая папка проекта; в ней уже находятся `site` и `amvera.yml`.
4. Из распакованного архива скопируйте папки `site`, `tests`, `scripts`, `docs` и файл `README_ORBIT_UPDATE_RU.md` в эту корневую папку.
5. Разрешите объединение папок и замену одноимённых файлов. Убедитесь, что в GitHub Desktop изменены только файлы, относящиеся к «Сокровищам орбиты». В архиве два заменяемых файла игры и четыре новых файла игры; остальные — тесты, сборка и описание.
6. В поле Summary напишите `Сокровища орбиты: 24 миссии и орбитальные комбо`.
7. Нажмите **Commit to main**. Это сохраняет изменения на компьютере.
8. Когда проверили игру и готовы опубликовать обновление, нажмите **Push origin**. Настроенная интеграция Amvera может автоматически развернуть новую версию и заменить реплику приложения.
9. Дождитесь статуса «Запущено» в Amvera и откройте каталог. На компьютере обновите страницу игры сочетанием **Ctrl+F5**, чтобы загрузились новые файлы.

Изменяется игра «Сокровища орбиты» и её описание в каталоге. Все 18 игр остаются в каталоге. Новых серверных зависимостей нет. Полный перечень механик и проверок находится в `docs/ORBIT_V2_RU.md`.

В ZIP нет конфигурации Amvera, токенов и настроек рекламы. Опубликованный сайт автоматически из этого чата не обновлялся: GitHub отклонил создание ветки с ошибкой 403.
