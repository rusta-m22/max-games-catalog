# 3.2.8 — выход из игры и восстановление оплаты

29 октября 2026, Екатеринбург.

- «Выйти из игры» доступно из главного меню и меню паузы; «Выйти» — в верхней панели на всех игровых экранах. Есть подтверждение и отмена. Перед закрытием сохраняются текущее поле и прогресс. Ошибка локального сохранения отменяет выход. Клиент закрывает окно через BrowserWindow.close(), с обычным beforeunload; облачная отправка ограничена по времени.
- Исправлен повтор оплаты после ошибки сохранённой ссылки: проверка прежнего заказа отделена от открытия платёжного окна. Явная «Новая попытка» проверяет прежний заказ, восстанавливает оплаченную покупку либо создаёт новый заказ для повторяемого пакета. Прежний заказ не удаляется и может принять запоздавший callback. Для одноразового стартового набора новая попытка по-прежнему не предлагается при неопределённом исходе.
- Добавлен журнал этапов оплаты с идентификатором пакета и кодом ошибки. Путь: `%APPDATA%/NonogramVKPlay/logs/checkout.log`. Журнал не содержит токенов, подписанных ссылок, ID пользователя/заказа или реквизитов карты.
- Новые тесты проходят по всем четырём пакетам и стартовому набору на уровне native-coordinator, отдельно проверяют восстановление пакета 3000 после отказа открывающего модуля, сохранение при выходе и закрытие реального EXE в Windows CI.

## Границы проверки

Пользователь сообщил: оплата 500, 1200 и 7000 открывается; 3000 — нет. Причина именно этого отказа пока не подтверждена: нет журнала проблемного запуска или доступа к его Windows Game Center. Найденный дефект повторной попытки воспроизводится тестом, но не объявляется доказанной причиной пользовательского случая.

На присланном скриншоте поддержка VK Play сообщает об отключении внедрения оверлея в Electron и просит очистить кэш Игрового центра. Эта операция на компьютере пользователя в данном сеансе не выполнялась. Команда оплаты остаётся `vkplay://demandbrowserform/` через Windows ShellExecute; внедрение DLL не включается.

Версия, идентификатор локального профиля, товары, цены и монеты не сбрасываются. Backend Miami, GCID 0.2046788 и GMRID 50675 остаются прежними. Сервер не требует обновления.

До повторной модерации необходимо проверить новую сборку через настоящий Game Center: открыть и закрыть без оплаты каждый из четырёх пакетов, проверить 3000 и оба способа выхода с восстановлением незавершённого поля. Автотесты с локальным платёжным сервисом не подтверждают видимость окна настоящего VK Play.

Официальное поведение закрытия: https://www.electronjs.org/docs/latest/api/browser-window#winclose
