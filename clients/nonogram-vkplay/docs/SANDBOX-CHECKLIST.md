# Протокол реального тестирования VK Play

Все строки: **NOT RUN**. Локальная имитация API не заменяет этот прогон. До платежа подтвердить именно тестовый биллинг в кабинете, ветку Test, тестовый аккаунт и актуальные тестовые реквизиты площадки. В публичной документации есть пример карты с устаревшим сроком — не заменять его настоящей картой.

Записать GMRID/GCID, SHA-256 настроенной сборки, версию backend, Windows и Game Center, дату и проверяющего. Для платежей: orderId, tid, баланс до/после, обезличенный журнал. Не записывать секрет, OTP, bearer-токены или полные подписанные URL.
