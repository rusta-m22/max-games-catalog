# Проверка штатного веб-окна Game Center

Это временная диагностика текущего проекта до публикации. Она открывает главную страницу VK Play, не создаёт заказ и не проверяет оплату. Наличие GAMINGFORMURL само по себе не доказывает исправление DemandBrowserForm.

## Что уже проверено

В присланном last.xml для build 6 (метка 3.2.5.) правильные GAMEID=0.2046788, ExeFileName64bit=Nonogram.exe и параметры передачи авторизации, языка, валюты. GAMINGFORMURL отсутствует. Поэтому штатная платёжная вкладка не настроена.

Все 7 размеров и MD5 из RunCheck совпали с файлами проверенного Windows ZIP 3.2.3. Сам установленный каталог на компьютере пользователя не прочитан; манифест не содержит хешей resources/app. Это сверка метаданных, не полная проверка установленной копии.

## Одно изменение в кабинете

1. Открыть проект «Нонограммы» → «Дистрибутивы» → «Изменить» → «Расширенные настройки клиента» (название может быть переведено в интерфейсе как дополнительные настройки).
2. Сохранить существующие строки и добавить отдельной строкой:

   ```ini
   GAMINGFORMURL=https://vkplay.ru/
   ```

   [Полный блок параметров](vkplay-overlay-diagnostic.ini) включает четыре уже проверенные строки и эту одну добавку. Путь исполняемого файла остаётся отдельным полем для 64-битной версии.
3. Сохранить параметры. По документации обновление занимает до 20 минут. После этого полностью закрыть Game Center через значок в трее, запустить заново и открыть существующую Test-игру. Для этой проверки не требуется новая сборка EXE или перенос в Live.
4. В игре нажать Ctrl+Alt+P либо Alt+Ё → вкладку пополнения. Ожидаемая страница — обычная главная страница VK Play. Проверяется только появление веб-окна.

Настройка задаётся в кабинете, а не правкой локального last.xml: нужно проверить именно конфигурацию, доставляемую платформой. После диагностики удалить временную строку; постоянную страницу оплаты нельзя подменять главной страницей сайта или callback URL.

## Как оценить результат

| Наблюдение | Что оно означает |
|---|---|
| Новая строка не появилась в свежем last.xml | Настройки ещё не доставлены; вывод о работе веб-формы делать рано |
| Строка появилась, вкладка и страница открылись | Штатный маршрут веб-формы работает; динамический DemandBrowserForm проверяется отдельно |
| Строка появилась, но нет вкладки или страницы | Нужна проверка механизма веб-формы Game Center/конфигурации проекта; новый заказ и изменения Amvera не являются проверкой этого механизма |
| Страница открылась, но покупка по-прежнему не показывает окно | Проверять динамический вызов SDK и его маршрутизацию в Electron отдельно от штатной вкладки |

Если параметры не применяются и после ожидания, документация предлагает очистку кэша. Она пока не выполнялась; сначала проверяется свежий last.xml.

Статус: инструкция и конфигурация подготовлены. Изменение в кабинете и этот запуск ещё не выполнены. Настоящий тестовый платёж и начисление монет остаются непроверенными.
