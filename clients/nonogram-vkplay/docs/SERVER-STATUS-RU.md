Для развёртывания подготовлена отдельная ветка **deploy/nonogram-vkplay-server** репозитория **rusta-m22/max-games-catalog**. В ней Dockerfile, amvera.yml и серверные файлы находятся в корне. Репозиторий публичный: для чтения GitHub токен не нужен. Ветка — фиксированная серверная поставка 3.2.0; изменения основной ветки не переносятся в неё автоматически.

В Amvera: существующий nonogram-miami → Репозиторий → «Подключить GitHub, GitLab, Bitbucket»; URL https://github.com/rusta-m22/max-games-catalog.git ; ветка deploy/nonogram-vkplay-server. Подключение/ручная сборка может начать платный запуск, поэтому сначала проверить выбранный тариф и согласовать расходы. Сборочный контейнер также тарифицируется.

После подключения: постоянный /data и одна реплика; параметры GMRID/секрет/API-каталог; подтверждённый IPv4 игрока через прокси; HTTPS и callback. Включать приём платежей только после подтверждения тестового режима площадки. /health в режиме ожидания должен вернуть 200, /ready — 503. Эти внешние проверки пока NOT RUN.

Старый nonogram-vkplay в Moscow-1 не используется; рабочие проекты пользователя не изменены. Отдельный Gateway не нужен: Windows-сборку на Test загружает bstool из GitHub, Amvera обслуживает backend покупок.
