# Загрузка Nonogram в VK Play

Версия 3.2.0. Клиент Windows 10/11 x64. В текущей поставке нет GMRID/GCID и адреса сервера: её можно проверить через Preview.cmd, но подключение покупок и проверка Game Center ещё впереди.

## Что потребуется один раз

1. Войдите в кабинет VK Play и выберите существующий проект игры. Тип проекта — клиентская Free-to-play игра. Не создавайте вторую игру, если проект уже есть.
2. В «Системных свойствах» нужны GMRID, GCID и Secret for Game API. GMRID и GCID не являются паролями. Секрет API внесите в секрет `VKPLAY_SECRET` проекта сервера Amvera; в переписку его отправлять не нужно.
3. Для Amvera используйте существующий `nonogram-vkplay`, **Miami-0**, один экземпляр и постоянный каталог `/data`. Серверная папка `server/` содержит самостоятельные Dockerfile и amvera.yml. После входа ассистент может загрузить файлы и выполнить проверку HTTPS. Адреса доверенных прокси нужно подтвердить по фактической конфигурации хостинга.
4. В VK Play создайте/проверьте пять товаров. Монеты: 500, 1200, 3000, 7000 и стартовый набор 800. Цены пока не назначены. `inventory-draft.json` — черновик без цен, его нельзя считать готовым каталогом. Реальные ID задаются на сервере в `VKPLAY_ITEMDEF_IDS`.
5. Укажите Callback URL: `https://АДРЕС-СЕРВЕРА/api/vkplay/callback`. Включите **тестовую платёжную систему** и убедитесь, что кабинет подтвердил переключение. Ветка Test сама по себе тестовую платёжку не включает.

## Параметры дистрибутива

«Дистрибутивы» → «Изменить»: в поле 64-bit — `Nonogram.exe`. Папка, которую получает загрузчик, должна содержать этот файл в корне и все соседние файлы. Отдельный установщик не нужен: установкой и обновлением занимается Game Center.

Дополнительные параметры клиента, каждую строку отдельно:

```ini
MyComUserIdParam=--sz_pers_id=
MyComCodeParam=--sz_token=
GameUILocaleParam=-my_ui_locale_arg=
GameUICurrencyParam=-my_ui_currency_arg=
```

После изменения настроек площадка может применять их до 20 минут.

## Минимум ручной работы через GitHub

После включения подготовленного workflow на основной ветке:

1. Repository → Settings → Secrets and variables → Actions → Variables: `VKPLAY_BACKEND_URL` — HTTPS-адрес сервера с `/` в конце; `VKPLAY_GCID` — GCID.
2. В Secrets добавьте `VKPLAY_BUILD_TOKEN`. Его берут в разделе «Дистрибутивы» под аккаунтом с ролью build manager. Не добавляйте сюда Secret for Game API: он нужен только Amvera.
3. Actions → Nonogram VK Play Windows → Run workflow. Без галочки `upload_test` получатся только сборка и проверки. С галочкой настроенный клиент загрузится в **Test** через официальный bstool.
4. Проверьте, что в «Дистрибутивах» действительно появилась новая Test-сборка. На Windows войдите в Game Center тем же аккаунтом и переключите игру на Test.

Workflow не переводит Test в Live. При каждой загрузке новая Test-сборка заменяет предыдущую. Постоянное хранилище сборщика на Amvera можно использовать позже, но для такого размера клиента отдельный Gateway не требуется: GitHub обращается прямо к VK Play, Amvera обслуживает игровые покупки.

## Вариант с обычным загрузчиком

Официальная утилита Windows: https://static.gc.vkplay.ru/guptools/win64.zip . Запустите GameCenterUploader.exe, выберите папку настроенного клиента и отдельную папку Assembly. Вставьте токен в поле Authorization token, нажмите Check the token → Start to Assemble. Это также загружает в Test. Пользоваться нужно настроенной пересобранной версией, не текущим preview.

## Перед выпуском

Выполнить `SANDBOX-CHECKLIST.md`: реальный GAS, overlay, каждый товар, отказ, закрытие оплаты, повтор callback, перезапуск и смена аккаунта. Реальные деньги и настоящие банковские карты не использовать. В публичном примере документации срок тестовых карт устарел; актуальные тестовые реквизиты берутся у площадки.

Перевод в Live и отправка на модерацию — только после отдельного согласия владельца. Для технической модерации VK Play проверяет ветку Live. При последующей отправке выбрать ручную публикацию, чтобы проверка не запустила выпуск автоматически.

Официальные источники проверены 19.10.2026: [дистрибутивы и bstool](https://documentation.vkplay.ru/f2p_vkp/f2pc_distrib_vkp), [клиентские платежи](https://documentation.vkplay.ru/f2p_vkp/f2pc_billing_vkp), [модерация](https://documentation.vkplay.ru/f2p_vkp/f2p_publish_vkp), [секреты GitHub](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets).
