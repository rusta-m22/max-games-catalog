# Клиент 3.2.3 — проверяемый вызов окна оплаты

В версии 3.2.2 успешное выполнение shell.openExternal означало передачу запроса обработчику протокола. Оно не доказывало появление формы, хотя текст игры утверждал обратное. В последнем видео форма не видна; журнал содержит опрос заказов, но не подтверждение callback.

## Изменено

- Windows x64 Node-API модуль вызывает документированный DemandBrowserForm непосредственно в процессе игры.
- Проверяются загрузка GCLay, IsGCConnected, результат вызова и GetOverlayState.
- Если модуль не внедрён, используется LoadLibraryEx по документированной переменной GC_GCLAY64_PATHNAME. Поиск DLL в текущем каталоге запрещён; чужой путь из renderer не принимается.
- Exact-host HTTPS проверка остаётся обязательной. Signed URL передаётся без изменения. Управляющие символы, userinfo, нестандартный порт и посторонние хосты отклоняются.
- Размеры формы оставлены нулевыми для стандартного расположения SDK; отображение на настоящем Game Center, в том числе размеры при HiDPI, требует проверки.
- Текст сообщает только о переданном запросе. Ошибки отсутствующего оверлея, разрыва связи и отказа SDK различаются.
- При неудачном открытии сохраняется прежний идентификатор попытки покупки. Серверная схема платежей и защита от повторного начисления не меняются.

## Проверки

Добавлены контракты JS-моста и локальная DLL-заглушка, которую настоящий упакованный Nonogram.exe загружает в Windows CI. Заглушка проверяет packed x64 ABI, точную передачу URL и обработку результата. Она не обращается к VK Play и не включается в поставку. Подлинная DLL Game Center также не распространяется вместе с игрой.

На момент подготовки PR проверки новой сборки ещё ожидают CI. Результаты будут записаны в отчёт после завершения. Нельзя считать этот тест проверкой настоящего оверлея, платежа или начисления монет.

## Официальные интерфейсы

- https://documentation.vkplay.ru/f2p_vkp/f2pc_overlay_vkp
- https://documentation.vkplay.ru/hotbox/devdocs/documents/gcdoc/2/GCLay.h
- https://www.electronjs.org/docs/latest/tutorial/using-native-node-modules

Сборка требует Windows x64 и C++ Build Tools. node-gyp 13.1.0 запускается через npm exec с соответствующими Electron 44.7.0 headers и delay-load hook. C++ runtime компонуется статически. Обновление Amvera для этого исправления не требуется. Автоматическая публикация Live не предусмотрена.
