# Что сделать сейчас — Nonogram VK Play

20 октября 2026 года. Новый клиент 3.2.1 проверен на Windows. Рабочий сервер пока 3.2.2; подготовлено обновление 3.2.3. Реальная тестовая оплата ещё не прошла.

1. **Amvera → nonogram-miami → Code.** Заменить только app.py и vkplay.py приложенными файлами, сохранив имена. Нажать сборку и запуск. Переменные, секреты, постоянный /data и регион Miami не менять. Альтернатива: загрузить содержимое папки Nonogram-VKPlay-Server из серверного ZIP в корень Code.
2. **Проверить сервер.** Открыть https://nonogram-miami-rustamr22.mia0.amvera.tech/health . Ожидается version=3.2.3-vkplay-server, configured=true, billingEnabled=true.
3. **VK Play → Дистрибутивы → Test.** Распаковать Windows ZIP 3.2.1 полностью. В официальном GameCenterUploader выбрать папку Nonogram-VKPlay-win-x64, где лежат Nonogram.exe и соседние файлы, и отдельную папку Assembly. Токен вводить только в защищённое поле загрузчика. Нажать Check the token → Start to Assemble. Live не переключать. Затем обновить Test-игру в Game Center и запустить оттуда.
4. **Магазин → 1200 монет.** При диалоге нажать «Новая попытка». Игра ещё раз проверит старый заказ, затем начнёт новый. Для стартового набора такую проверку не использовать: он одноразовый. Реальную карту не вводить.
5. **Amvera → Логи → Приложение.** Если форма не открылась, прислать только строку `VK Play checkout response reason=payment_url_not_allowed ...`, где будут тип/протокол/домен. Платёжную ссылку целиком, пароль и токены не присылать. До этого фактический домен прежней ссылки неизвестен.

Настройка callback уже проверена: VK Play → «Страница» → «URL обратного вызова» содержит https://nonogram-miami-rustamr22.mia0.amvera.tech/api/vkplay/callback . Тестовый режим в кабинете включён. Повторно создавать приложение, товары или сервер не нужно.

Автоматизация записи в Amvera заблокирована защитой браузера текущего сеанса; изменения туда ещё не применены. Новый клиент в Test автоматически не загружался. Эти два ручных обновления нужны для следующей фактической проверки.
