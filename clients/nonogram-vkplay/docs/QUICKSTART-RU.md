# Nonogram 3.2.3: что сделать в VK Play

[Скачать Windows ZIP 3.2.3](https://github.com/rusta-m22/max-games-catalog/actions/runs/39461965930/artifacts/12282324110) · [Результаты проверок](READINESS-RU.md)

Эта версия исправляет вызов окна оплаты. Amvera для данного обновления менять не нужно.

1. Скачать готовую Windows-сборку по ссылке из отчёта. Если скачан артефакт windows-zip, внутри находится архив Nonogram-VKPlay-Windows-x64-3.2.3.zip — распаковать и его.
2. В официальном GameCenterUploader выбрать всю папку **Nonogram-VKPlay-win-x64**, где находятся Nonogram.exe и соседние файлы. Загрузить в **Test** существующего проекта. **Live не переключать.** Токен вводится только в защищённое поле загрузчика.
3. Обновить тестовую игру через Game Center и запустить оттуда. В магазине открыть повторяемый пакет **1200 монет**. Если есть старый неопределённый заказ, использовать видимую кнопку «Новая попытка»: игра сначала проверит прежний заказ. Одноразовый стартовый набор пока не использовать.
4. Проверить появление формы. Сообщение «Запрос окна оплаты передан VK Play» означает принятие запроса, а не доказанный показ формы или оплату. Если формы нет, нужен точный текст новой ошибки или запись экрана. Полную платёжную ссылку, пароль и токены присылать не нужно.

Настоящий платёж пока не подтверждён. После появления формы использовать только официальную тестовую среду и актуальные тестовые реквизиты VK Play. Реальную карту не вводить. Должны отдельно пройти: успешное тестовое начисление один раз, отмена/отказ без начисления, повтор callback без дубликата и сохранение после перезапуска.

Для справки: callback существующего проекта — https://nonogram-miami-rustamr22.mia0.amvera.tech/api/vkplay/callback . Настройка сервера VKPLAY_PAYMENT_HOSTS должна содержать vkplay.ru,co.vkpay.ru; она уже поддерживается backend 3.2.3. Новый отдельный Gateway не требуется.

Архивы GitHub Actions хранятся 14 дней; скачать до истечения срока, указанного в отчёте. Код и процедура повторной сборки сохранены в GitHub.
