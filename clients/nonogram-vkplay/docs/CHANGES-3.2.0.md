# Nonogram VK Play 3.2.0

Источник: rusta-m22/max-games-catalog, site/games/nonograms, commit 28aef6a74ad6bce13310c482070eed0c481aaa86; продолжение клиентской адаптации 3.1.0 и сервера 3.1.1 из материалов 13–14 октября.

- Исправлен преждевременный синхронный IPC-ответ при сохранении: успешная запись теперь возвращает true один раз после завершения. Ошибка вызывала откат покупки подсказки на Windows.
- Добавлены иконка и сведения о продукте в Nonogram.exe; изменённый EXE не подписан сертификатом издателя.
- Однозначный отказ создания checkout освобождает возможность новой попытки, включая стартовый набор. Тайм-аут остаётся unknown, начисления без callback нет.
- Поздний успешный callback позволяет восстановить оплаченный заказ без ранее полученного checkout URL.
- Добавлены проверка всех 507 головоломок, соответствия клиента и сервера и проверки безопасности загрузчика.
- Подготовлен GitHub workflow: Windows EXE → локальные тесты → настоящий Windows запуск → архив. Опциональная загрузка через bstool ограничена Test.
- Утилита загрузки сверяет файлы и хеш официальных инструментов, получает токен из защищённой переменной и очищает его из вывода. Произвольных команд и переключения Live в ней нет.

Параметры реального проекта не подключены. Платежи VK Play, GAS и overlay не проверены на площадке. Текущее наличие workflow и результаты Windows CI фиксируются в итоговом отчёте, а не предполагаются по наличию YAML.
