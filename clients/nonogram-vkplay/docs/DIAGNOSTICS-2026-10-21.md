## Сверка кода и документации

Упаковка структуры, порядок полей, размер x64 (52 байта), имена функций и переменная GC_GCLAY64_PATHNAME соответствуют опубликованному GCLay.h. Подписанный платёжный URL передаётся без изменения. В коде размеры формы нулевые; явной спецификации семантики нулей для прямого SDK-вызова в заголовке нет. Документация страницы описывает стандартный размер 80%, но фактическое отображение этой реализации требует проверки.

GAMINGFORMURL задаёт отдельную штатную платёжную вкладку и сохраняется в Misc файла -gup-/last.xml. Документация описывает DemandBrowserForm с произвольным URL отдельно и не устанавливает для него явную зависимость от GAMINGFORMURL. Поэтому отсутствие вкладки нельзя объявлять доказанной причиной отказа динамической формы.

Инструкция Debug Console относится к BrowserClientX86/BrowserClientX64 с BrowserApp*.ini. Наличие такого компонента в поставке нашей Electron-игры не подтверждено; применять эту инструкцию к ней без проверки нельзя.

## Результат проверки last.xml

Полученный файл прочитан локально. Он указывает Manifest Build=6, VersionNum=3.2.5., GAMEID=0.2046788, ExeFileName64bit=Nonogram.exe. Четыре параметра передачи UID, одноразового кода, языка и валюты соответствуют клиенту. Пустое 32-битное поле допустимо для игры только x64. В Misc нет GAMINGFORMURL: штатная платёжная вкладка не настроена.

Повторно скачан артефакт GitHub 12282324110. Проверены ожидаемые SHA-256 внешнего архива и вложенного Windows ZIP; package.json внутри имеет версию 3.2.3. Все 7 размеров и MD5 из RunCheck совпали с файлами этой сборки. Nonogram.exe: размер 246302208, MD5 7015AA7B025043DF97194749ADA260E0. [Результаты сравнения](MANIFEST-COMPARISON-2026-10-21.json).

Это сопоставление манифеста, а не хеширование файлов на компьютере пользователя. Хешей resources/app в last.xml нет, поэтому целостность всей установленной копии этим не доказана.
