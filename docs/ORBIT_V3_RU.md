# Сокровища орбиты — 3D-экспедиция, версия 3

Обновление от 3 октября 2026 года для `rusta-m22/max-games-catalog`.
Архив содержит полное накопительное обновление игры: его можно установить поверх исходного каталога или версии 2.

## Новое в версии 3

- Настоящая сцена Three.js с перспективной камерой. Поле находится на парящей платформе с объёмным корпусом, золотой окантовкой, светящимися двигателями и орбитальным кольцом.
- Шесть геометрий самоцветов с короной, гранями и нижней частью. Свет, отражения и небольшое покачивание подчёркивают объём. Модели, окружение и звук создаются кодом; внешние игровые ассеты не загружаются.
- Более красочное космическое оформление, планеты, звёзды, дрон «Искра», новые кнопки усилителей, карта орбит и индикатор возможных звёзд.
- Обмен кристаллов по дуге, падение с края платформы, объёмные осколки, лучи, ударные кольца, всплывающие очки и перелёт энергии к реактору.
- Новый бонус «Резонанс»: не менее трёх каскадов в основной цепочке одного действия дают +8 заряда реактора. Бонус начисляется один раз за действие, заряд ограничен 36. Срабатывает и после обмена, и после усилителя; отдельная цепочка звёздного дождя не даёт второй бонус.
- Синтезированные звуковые эффекты: каскад повышает тон, импульс, резонанс и победа имеют отдельные сигналы. Звук выключается общей кнопкой, при рекламе и скрытии вкладки приостанавливается.
- Области нажатия рассчитываются по той же 3D-камере, что рисует камни. Наклон поля не смещает выбор пальцем. Клавиатурное управление сохранено.
- Адаптивная плотность рендеринга, ограниченное количество частиц, инстансинг клеток и теней. Настройка уменьшенной анимации учитывается. Если WebGL недоступен, включается играбельный Canvas 2D.

Демонстрационный MP4 показывает реальный тестовый прогон в браузере: запись ускорена в три раза и не содержит звука. Это обзор эффектов, а не измерение частоты кадров.

## Экспедиция

Сохраняются 24 миссии и три сектора: Кольца Авроры, Пояс Титана, Туманность Эха. Есть задания на энергию, цвета, астероиды и артефакты, лучи за четыре камня, сверхновая за пересечение, призма за пять камней и комбинации усилителей. Импульс очищает выбранные строку и столбец, два бура доступны на каждую попытку. Подсказка бесплатна.

В Поясе Титана каждые пять обычных ходов звёздный дождь помогает разрушать астероиды. В Туманности Эха каждые четыре обычных хода поворачивается гравитация. Карта открывается последовательно, звёзды и лучшие результаты сохраняются.

## Сохранения

Версия 3 продолжает использовать `jarvis-orbit-expedition-v2`: открытые миссии, звёзды и текущая партия версии 2 совместимы. Результат действия, включая резонанс, сохраняется целиком до анимации. Старое сохранение `jarvis-orbit` не удаляется; его уровень переносится в количество открытых миссий.

Сохранения локальны для браузера и адреса сайта. Прогресс из отдельного HTML не переносится автоматически на сайт Amvera.

## Проверки этой версии

- 15 наборов тестов правил: 480 начальных полей, специальные комбинации, бонус резонанса и его предел, сохранения, события, победа на последнем ходу и длинные партии во всех секторах.
- 33 сценария Chromium: настоящее WebGL, перспективная проекция, все 64 области нажатия, мышь, сенсорный свайп и его отмена, клавиатура, карта, усилители, сохранение резонанса, победа/поражение и восстановление после повреждения сохранения. Необработанных ошибок JavaScript нет.
- Готовый HTML проверен офлайн на 1366×768, 390×844, 360×640, 320×640. На всех четырёх размерах усилители помещаются в экран, горизонтальной прокрутки нет, все клетки доступны, обмен выполняется.
- Аудит каталога: 507 файлов, 147 локальных ссылок, 18 игр; проверки HTTP, MIME, CORS и 404 пройдены.
- Логика «Кубомании 3D» и остальные записи каталога сравнены с исходной версией и сохранены.

Мобильные проверки выполнены в Chromium с эмуляцией. Проверка внутри MAX на физическом телефоне не выполнялась; производительность на реальном устройстве не измерялась.

## Запуск проверок и сборка

```sh
node tests/orbit.test.mjs
npm run audit
node scripts/build-orbit-preview.mjs
```

Браузерный тест: `node tests/orbit-browser.mjs`. Нужны Playwright и Chromium; при нестандартной установке используются `PLAYWRIGHT_MODULE`, `CHROMIUM_PATH`, `QA_OUTPUT`. Тест работает с локальными файлами и не меняет опубликованный сайт.

Сборка создаёт `Sokrovishcha_Orbity_3D_v3.html` — автономную игру без серверных зависимостей. Общий шрифт каталога в автономной версии заменён системным. Реклама в ней отключена.

В архиве только файлы обновления, без токенов и конфигурации размещения. Перед Push сначала проверьте автономную игру и список изменений в GitHub Desktop.
