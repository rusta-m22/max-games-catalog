# Сокровища орбиты — Звёздный атлас, версия 2

Обновление от 3 октября 2026 года для `rusta-m22/max-games-catalog`.
База: `main`, коммит `5c0b0f34e4faee2e8885b609bdad2811d374a768`.

## Что изменилось

- Экспедиция из 24 миссий в трёх секторах: Кольца Авроры, Пояс Титана, Туманность Эха.
- Карта с последовательным открытием миссий, повторным прохождением, лучшими результатами и звёздами. В конце каждого сектора открывается реликвия атласа.
- Отдельные задания на энергию, нужные цвета кристаллов, разрушение астероидов и поиск находок под корой. Шесть схем расположения астероидов, однослойная и двухслойная кора.
- Четыре в ряд создают луч; пересечение — сверхновую; пять в ряд — призму. Можно соединять два специальных кристалла, в том числе две призмы или луч со сверхновой.
- Орбитальный импульс заряжается от собранных кристаллов. При 36 единицах очищает выбранные строку и столбец без расхода хода.
- Два точечных бура на попытку, бесплатная подсказка, автоматическое перемешивание поля без допустимых ходов.
- Звёздный дождь каждые пять обычных ходов в Поясе Титана: три удара по астероидам и восемь единиц заряда. В Туманности Эха каждые четыре обычных хода меняется направление следующих падений.
- Видимые обмены, падения, частицы, лучи, взрывные кольца, сообщения о каскадах, счётчики целей и экран результата.
- Управление мышью, свайпом и клавиатурой; режим уменьшенной анимации. При недоступном WebGL используется Canvas 2D.
- Сохранение всего результата хода до воспроизведения анимации. Перезагрузка во время каскада возвращает завершённый ход. Звёзды, лучшая оценка и открытые миссии сохраняются на этом устройстве.
- Старое сохранение `jarvis-orbit` не удаляется. Его номер уровня переносится в число открытых миссий (максимум 24). Сама текущая попытка старой версии не переносится, поскольку изменились цели.

Сохранение новой версии: `jarvis-orbit-expedition-v2`. Облачной синхронизации прогресса в этой версии нет. Автономный HTML и опубликованный сайт используют разные хранилища браузера.

## Проверки

- 56 тестов всего каталога пройдены, включая 14 наборов проверок правил новой игры.
- Проверены 480 начальных полей, специальные комбинации, последний ход, целостность объектов и сохранений, события и множество последовательных ходов.
- Алгоритм подбора ходов прошёл каждую из 24 миссий на шести начальных полях (144 симуляции). Это проверка достижимости целей; она не заменяет оценку сложности живыми игроками.
- 29 проверок в Chromium: WebGL, ввод мышью и настоящие сенсорные события, отмена свайпа, клавиатура, подсказка, карта, закрытые миссии, бур, импульс, перезагрузка, победа/поражение, повтор, восстановление повреждённого сохранения, Canvas 2D. Необработанных ошибок JavaScript не обнаружено.
- Проверены размеры 1440×1000, 390×844, 360×640, 320×640 и 844×390. Дополнительно проверяется готовый HTML на 1366×768 и маленьких телефонах.
- Аудит каталога: 506 файлов, 146 локальных ссылок, 18 игр; HTTP, MIME и отсутствие доступа к конфигурационным файлам проверены.

Мобильные проверки выполнены в Chromium с эмуляцией сенсорного экрана. Проверка внутри приложения MAX на физическом телефоне остаётся отдельным шагом перед выпуском.

## Сборка и запуск проверок

```sh
npm test
npm run audit
node scripts/build-orbit-preview.mjs
```

Для реальных браузерных сценариев нужен Playwright и Chromium:

```sh
node tests/orbit-browser.mjs
```

При нестандартной установке задайте `PLAYWRIGHT_MODULE`, `CHROMIUM_PATH` и `QA_OUTPUT`. Браузерный тест отдаёт локальные файлы через перехват запросов и не обращается к опубликованному сайту.
