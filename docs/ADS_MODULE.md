# Единый рекламный модуль — API v1

Модуль изолирует игры от рекламных SDK. Игровой код знает только, что раунд завершён или игрок запросил награду. Адаптер знает методы и события своей площадки. Решение, сколько подсказок или бонусов начислить, остаётся в игре.

## Подключение

Скопируйте в корень сборки `ads-config.js`, `ads-loader.js`, папку `shared/ads/`, а для VK также `vendor/vk-bridge.js` и её лицензию. Подключите перед игровым кодом:

```html
<script src="ads-config.js"></script>
<script src="ads-loader.js"></script>
```

```js
const ads = await window.JarvisAdsReady;
const {capabilities} = await ads.ready();

// Вызывать один раз после завершения раунда, перед следующим.
await ads.afterRound({gameId: 'my-game', roundId: uniqueRoundId});

// Обработчик кнопки «Подсказка за видео».
async function requestHint() {
  const result = await ads.rewarded({
    gameId: 'my-game', placement: 'hint', requestId: uniqueAttemptId
  });
  if (result.rewarded) addOneHint();
}
videoButton.hidden = !capabilities.rewarded;
```

`uniqueRoundId` и `uniqueAttemptId` создаёт игра: новый ID для нового запроса, тот же ID для повторной доставки одного события. Модуль запоминает последние 500 запросов в текущей странице. Это защита от повторных вызовов UI, а не серверный учёт валюты.

Результат — объект `{platform, shown, rewarded, reason, requestId?}`. Примеры `reason`: `closed`, `cancelled`, `no-fill`, `unsupported`, `max-disabled`, `disabled`, `busy`, `cooldown`, `background`, `duplicate`, `sdk-error`, `offline`, `timeout`, `reload-required`, `module-unavailable`. Проверяйте `rewarded === true`, а не только `shown` или `reason === 'closed'`.

## Пауза

```js
window.addEventListener('jarvis-ads-pause', () => {
  pauseGameplayAndAudio();
});
window.addEventListener('jarvis-ads-resume', () => {
  if (!document.hidden && !isPauseMenuOpen()) resumeGameplayAndAudio();
});
```

События отправляются и в дочерние iframe того же origin. Такие iframe переиспользуют менеджер родителя — второй параллельный показ не создаётся. Игра также должна учитывать `visibilitychange` и собственную ручную паузу.

Таймаут запроса — 120 секунд. Неподтверждённая награда не начисляется; новые показы блокируются до перезагрузки, поскольку SDK может не поддерживать отмену уже открытого окна. Поздние callback игнорируются.

## Определение площадки

Приоритет MAX выше всех подсказок конфигурации и глобальных SDK. Учитываются данные запуска `WebApp`, параметры MAX и его домен. Проверка повторяется перед каждым рекламным вызовом: поздняя инициализация моста MAX также выключает показ. `maxEnabled: true` не может обойти блокировку.

После MAX учитываются явная конфигурация, настоящий SDK/домен Яндекс Игр и параметры запуска/окружение VK Mini Apps. Подключённый совместимый порт `YaGames.__jarvisCompat` сам по себе не означает Яндекс Игры. Неизвестная площадка получает DisabledAdapter.

SDK Яндекса загружается по официальному `/sdk.js` только при выборе Яндекса. VK Bridge загружается из локальной проверяемой копии. Технический домен VK Cloud сам по себе не включает рекламу VK.

## Новый адаптер

Добавьте класс в новую версию центрального модуля и зарегистрируйте его в `index.js`, при необходимости расширьте `detect.js`. Игры не меняются.

```js
class ExampleAdapter {
  platform = 'example';
  capabilities = {interstitial: false, rewarded: false};
  async init() {
    // Инициализация официального SDK, проверка доступных методов.
  }
  async show(type, {signal, onOpen}) {
    // type: interstitial | rewarded.
    // Учитывать AbortSignal и отбрасывать поздние callback.
    // onOpen() — при открытии. Не подменять успешное вознаграждение закрытием.
    return {shown: false, rewarded: false, reason: 'no-fill'};
  }
}
```

Сначала добавьте тесты адаптера: отсутствие рекламы, отмена, подтверждение награды, ошибка, повторный callback, таймаут. Для будущего MAX адаптер подключается только после ответа площадки и явного решения включить её; в текущей версии запрет намеренно жёсткий.

## Центральные обновления и откат

1. Разместите `shared/ads/` на собственном HTTPS-домене. CORS для манифеста и файлов модуля должен разрешать origin ваших сборок; приложенный Caddyfile использует публичный `*` только для этих общедоступных файлов, без credentials.
2. Один раз задайте одинаковый `moduleBase` во всех сборках. Пример: `https://games.example.com/shared/ads/`.
3. Для релиза создайте новую папку, например `v1.0.1/`, с `index.js`, `adapters.js`, `detect.js`, `coordinator.js`. Сначала загрузите её целиком.
4. После проверки атомарно замените манифест:

```json
{"apiVersion":1,"version":"1.0.1","entry":"v1.0.1/index.js"}
```

5. Для отката верните прежний `entry`. Старые папки не удаляйте, пока ими могут пользоваться открытые страницы.

Манифест запрашивается без кеша, с таймаутом 2,5 секунды. Путь entry должен оставаться на том же origin и внутри moduleBase. Импорт модуля ограничен 4,5 секунды; при сетевом сбое используется локальная `v1`. Открытая страница сохраняет выбранную версию до следующей загрузки. Центральные файлы необходимо менять только доверенному администратору: это исполняемый код всех подключённых игр.

Изменение `apiVersion` требует совместимого загрузчика; для добавления обычных адаптеров сохраняйте API v1. Bootstrap, конфигурация и локальная резервная версия поставляются в каждой сборке. Их собственное обновление требует нового выпуска этой сборки.

## Старые HTML5 и Godot

`legacy-platform.js` адаптирует прежние вызовы полноэкранной/rewarded рекламы к общему менеджеру и выдаёт локальный гостевой профиль, если аккаунт площадки недоступен. Это не реализация всего SDK Яндекса: покупки, серверная авторизация, лидерборды и сеть не эмулируются.

В переданном каталоге интеграция выполнена. Для новой игры достаточно API выше; совместимый порт нужен только для старых экспортов. В БУМбиле текстовый Godot-мост наблюдает существующие поля `level_complete`/`game_over` и вызывает `JarvisGameRoundEnded`. Награда проходит по прежнему JS-мосту через общий модуль.
