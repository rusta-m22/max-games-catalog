# ИГРЫ №1 В MAX

Пакет с обновлением «19 игр»: каталог из 19 игр, исходники новых игр, перенесённые HTML5-сборки, единый рекламный модуль и конфигурация размещения на сервере VK Cloud. «МЕМасики» исключены. «Слияние чисел» переделано в игру с бросками 3D-кубиков, столкновениями и цепочками слияний. Подробности: `docs/MERGE_3D.md`.

Новое обновление: «Острова кубиков 3D» (рекорд и 18 островов) и «Сокровища орбиты v4» на весь доступный экран. Инструкция установки, результаты проверки и статус публикации: `README_UPDATE_19_RU.md`.
## Запуск

Для локального просмотра установите Node.js 22 LTS или новее и выполните из папки проекта:

```sh
node serve.mjs
```

Откройте http://127.0.0.1:8080/. На Windows можно запустить `START_LOCAL.bat`. Открывать `index.html` двойным щелчком через `file://` нельзя: модулям и WebAssembly нужен HTTP-сервер. Для такого просмотра `npm install` не требуется; браузерные зависимости уже находятся в `site/vendor`.

## Что размещать

Папка `site/` — готовый статический сайт. Загрузите её содержимое с сохранением вложенных путей. Сборка, база данных и Node.js на публичном сервере не требуются. Нужен HTTPS и корректный MIME для `.js` и `.wasm`. Инструкция для сервера — `docs/VK_CLOUD.md`.

В этой передаче сайт не опубликован: браузер ChatGPT блокирует доступ к `msk.cloud.vk.ru`, поэтому выданную роль и ресурсы проекта проверить не удалось. Платные ресурсы не создавались.

Сетевые партии пока не включены. Прогресс новых игр хранится на устройстве в браузере; очистка данных браузера его удалит. Синхронизации аккаунтов MAX между устройствами в этом пакете нет. Две новые 3D-игры требуют WebGL. Для БУМбилы сохранён WebAssembly-экспорт Godot из предоставленной сборки.

## Единая реклама

Все игры используют общий модуль `site/shared/ads/`. Новые игры вызывают `afterRound()` и `rewarded()` через фасад; старые HTML5-игры подключены через `legacy-platform.js`. В БУМбиле дополнен текстовый мост `platform_bridge.gd`: окончание уровня или партии передаётся в общий модуль, остальные 46 ресурсов PCK сохранены без изменений. Исходник моста и воспроизводимый скрипт его упаковки приложены.

| Площадка | Поведение |
|---|---|
| MAX | Реклама жёстко отключена, награда за просмотр не выдаётся |
| Яндекс Игры | Адаптер полноэкранной и вознаграждаемой рекламы |
| VK Mini Apps | Адаптер VK Bridge для interstitial и reward |
| Обычный сайт, включая размещение в VK Cloud | Игра работает без рекламы |

VK Cloud — хостинг, а не рекламная площадка. Адаптер VK Mini Apps не является адаптером VK Play или AppLovin MAX.

Полноэкранная реклама вызывается между завершёнными раундами, с общим ограничением частоты в открытой странице — не чаще одного показа за 90 секунд. Rewarded запускается только по действию игрока. Награда выдаётся только после подтверждения SDK; закрытие без подтверждения, отсутствие рекламы, ошибка или таймаут награды не дают. При показе приостанавливаются игра и звук. После таймаута новые запросы блокируются до перезагрузки, чтобы не открыть вторую рекламу поверх неизвестного состояния первой.

На MAX и обычном сайте рекламные кнопки новых игр и доступные DOM-кнопки старых сборок скрыты. Интерфейс БУМбилы нарисован внутри исходного Godot-экспорта: его встроенное предложение продолжения может остаться видимым, но отключённый адаптер не покажет рекламу и не выдаст ложную награду.

## Обновления всех сборок

Общий загрузчик подключён к каталогу из 19 игр. Внутри этого каталога они используют одну копию модуля. Для отдельно размещённых сборок один раз укажите общий HTTPS-адрес:

```sh
node scripts/configure-origin.mjs https://ВАШ-ДОМЕН
```

Команда меняет `moduleBase` в `site/ads-config.js`. С этим же значением нужно выпустить остальные сборки. После этого новые версии модуля публикуются централизованно через `shared/ads/manifest.json`; игры менять не нужно. Обновление применяется при следующей загрузке страницы. При недоступности центра используется локальная резервная версия.

Старые уже опубликованные сборки без этого загрузчика автоматически обновиться не могут: сначала им потребуется однократное подключение. Возможность загрузки внешних модулей также должна разрешаться правилами и CSP конкретной площадки. До появления домена `moduleBase` оставлен пустым, работает локальная версия.

Подробный API, создание адаптера и выпуск обновлений: `docs/ADS_MODULE.md`.

## Проверки и передача

`npm ci && npm test` запускает тесты правил, рекламного модуля и взаимодействий с DOM. `node scripts/audit.mjs` проверяет локальные ссылки и запуск статического сервера. Результаты и границы проверки — `docs/VALIDATION.md`.

«Слияние чисел» проверено в Chromium с WebGL (программный GPU), включая мышь, клавиатуру, сенсорные жесты, сохранение и телефонные размеры экрана. Это не заменяет проверку на физических устройствах и внутри MAX. Остальные 3D-игры, Godot на телефоне и реальные рекламные показы по-прежнему требуют проверки на целевых устройствах. Наличие адаптера само по себе не подключает монетизацию: приложение должно иметь соответствующий доступ на площадке.
